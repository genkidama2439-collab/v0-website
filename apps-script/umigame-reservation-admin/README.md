# 海亀兄弟 予約管理GAS

このフォルダを、海亀兄弟の予約管理Google Apps Scriptの管理場所として使います。

## 重要

- `docs/gas-line-notify.js` は旧参考ファイルです。本番へ貼り付けないでください。
- `Code.gs`はリポジトリ上の最新版です。本番反映状況は必ず`LATEST.md`を確認してください。
- 未反映の変更を作るときだけ`Code.next.gs`を作成し、本番反映後は`Code.gs`へ昇格します。
- 反映前の旧版は`archive/`へ保存します。
- `Code.gs`の一部を別ファイルへ切り出してGASへ置かないでください。末尾のLINE安全送信ブロックは
  既存関数を包む実装のため、同じ内容が2ファイルに存在すると二重に適用されます。

## 現在管理している最新版

| ファイル | 内容 | 状態 |
|---|---|---|
| `LATEST.md` | 今見るべき最新コードと本番反映状況 | 運用中 |
| `Code.gs` | リポジトリ上の最新版 | 紹介制度と49列スキーマを追加した`2026.08.24-1`。本番未反映 |

## 今後のルール

1. GASを変更するときは、必ずこのフォルダのファイルを先に更新します。
2. 変更した日付・内容・本番反映状況を`CHANGELOG.md`へ記録します。
3. 本番へ反映したら、同じ内容になっていることを確認します。
4. シート列を追加・変更するときは、管理Webアプリ側の`ADMIN_COLUMNS`・`ADMIN_CANONICAL_HEADERS`とも一致させます。
5. `NOTIFY_SECRET`などの秘密情報はファイルへ書かず、Script Propertiesで管理します。

## 現在のLINE送信方法

M・N・S列を編集しても即送信されません。U列の送信予定を確認し、T列をチェックしたときだけLINEを送信します。送信内容と結果は`LINE送信履歴`シートへ記録されます。

## 紹介制度の初期設定

本番反映後、Apps Scriptエディタから`setupReferralProgram()`を1回実行します。既存予約を削除・上書きせず、予約一覧の末尾へ紹介4列を追加し、`紹介者マスタ`・`紹介報酬ルール`・`紹介成果`を作成します。`kaita / かいた君 / PERCENTAGE / 50`は未登録の場合だけ追加されるため、再実行しても重複しません。

紹介者追加と基本報酬変更は`紹介者マスタ`、プラン別の上書きは`紹介報酬ルール`を編集します。報酬方式は`PERCENTAGE`・`FIXED_BOOKING`・`PER_PARTICIPANT`のいずれかを使用します。

## 本番反映後の更新

新しい変更を作るときは`Code.gs`を元に`Code.next.gs`を作成します。本番反映と確認が完了したら、旧`Code.gs`を`archive/`へ退避し、`Code.next.gs`を`Code.gs`へ昇格します。
